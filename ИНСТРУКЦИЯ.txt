============================================================
 SONIC.EXE THE DISASTER 2D REMAKE — порт на Godot (этап 1)
============================================================

ЗАПУСК:
  Дважды кликни "ИГРАТЬ.bat" — откроется игра в окне 480x270.

  (Или через консоль: Godot\Godot_console.exe --path эту_папку)

ЧТО СДЕЛАНО НА ЭТАПЕ 1 (меню 1:1):
  - Заставка (POWERED BY GAMEMAKER -> EXE EMPIRE PRESENTS -> меню),
    скипается любой клавишей/кликом — как в оригинале
  - Главное меню: логотип, анимированный персонаж справа, частицы,
    тайловый фон с heat-haze шейдером, ссылки (Discord/Roblox/
    GameJolt), банер Luigikid, версия "v mod1101", монетка-донат
  - JOIN GAME: карта мира, метки серверов (в оригинале тоже точки),
    поле ввода IP (с поддержкой Ctrl+V), BACK
    * само подключение к серверам — ЭТАП 2 (сетевой код), сейчас
      нажатие по серверу ничего не делает
  - OPTIONS: ник (до 15 симв.), размер экрана (480/960/1440/фуллскрин),
    скрыть пинг/FPS, GENERAL/CONTROLS/BACK
  - OPTIONS -> CONTROLS: переназначение клавиш (подойди, нажми Z,
    нажми новую клавишу), сброс дефолт, назад
  - EXTRA: ачивации (50 шт., скролл стрелками/колёсиком), меркоины,
    скины (карточки, цены, EQUIPPED), иконки, петы, таунты, донат-попап
  - ABOUT: гейм-механики (11 страниц с гиф-демо), инфо по персонажам
    (10 страниц), титры (скроллятся), секретные коды на экране титров
  - Секретные коды pet-ов (вводятся на экране CREDITS) работают
  - Меню полностью на мышке и клавиатуре: стрелки/WASD-бинды, Z=ок, X=назад

СОХРАНЕНИЯ:
  user:// (AppData\Roaming\Godot\app_userdata\...) — формат тот же,
  что у оригинала (1.bson/2.bson XOR 69, 3.bin), но со старыми сейвами
  оригинала официально не совместимо на 100% (другой движок).

УПРАВЛЕНИЕ (дефолт):
  Стрелки — навигация, Z — выбрать, X — назад, Esc — назад в меню

ЭТАП 2 (ГОТОВО) — СЕТЬ:
  Сервер — ОТДЕЛЬНОЕ приложение: Desktop\DisasterServer-Godot
  (START_SERVER.bat, окно как у BetterServer: лог, кнопки,
  MAIN|OPTIONS|PLAYERS|INFO, Config.json/Bans/Operators)
  Клиент: JOIN GAME → Enter (localhost) → waiting → лобби →
  READY (Z) → голосование за карту → выбор персонажа →
  GAME START. Чат: Enter. Сервер авторитетный (античит-модель
  оригинала). Тест по сети: второй игрок вписывает твой IP.

ЭТАП 3 (ЧАСТЬ 1) — ГЕЙМПЛЕЙ:
  Карта "..." (DotDotDot) + Соник.exe (EXE_ORIGINAL) играбельны.
  ОДИНОЧНЫЙ ЗАПУСК: запусти сервер (ЗАПУСТИ СЕРВЕР.bat) →
  зайди в игру (ИГРАТЬ.bat) → JOIN GAME → Enter → на сервере
  нажми PRACTICE MODE → тебя перебросит на карту Соник.exe'ем.
  Управление: стрелки/WASD-бинды = бег, Z = прыжок, X = атака-
  рывок, C = невидимость (15 сек, перезаряд 20 сек), W в стойке =
  смотреть вверх, S на месте = присесть, A/S/D = эмоции (часть
  открывается в Extra). Esc на карте = выход в меню.
  Кольца собираются, шипы/падение бьют, пружины работают.

  Пока только карта "..." в соло. Этап 3.5: остальные карты,
  мультиплеер-синхронизация игроков на карте, минигейм в
  waiting, результаты раунда, выжившие.

ТЕХ. ДЕТАЛИ:
  - Godot 4.7.2, viewport 480x270, stretch viewport + integer scale,
    nearest фильтрация — пиксель-перфект
  - Логика на фиксированных 60 Гц (как GameMaker room speed 60)
  - Отладочные автолоады (dbg_shot/dbg_probe) неактивны без env-переменных
